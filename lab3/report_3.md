## **№1. Задание 1.1**

**Дом над землей.**
Измените сущность Дом. Гарантируйте, что у дома всегда будет положительное количество этажей. В случае попытки указать отрицательное количество этажей должна выбрасываться соответствующая ошибка.

**Алгоритм решения.**
Класс `Home` содержит поле `private final int floor`. Модификатор `final` гарантирует, что количество этажей не может быть изменено после создания объекта. В конструкторе добавлена проверка: если переданное значение `floor <= 0`, с помощью оператора `throw` выбрасывается исключение `IllegalArgumentException` с поясняющим сообщением. В методе `main` создание объекта обернуто в блок `try-catch` для перехвата и корректного вывода ошибки без аварийного завершения программы.

## **№2. Задание 1.5**

**Перезарядка Пистолета.**
Модификация сущности Пистолет: имеет максимальное количество патронов (устанавливается при создании), может быть перезаряжен (с возвратом лишних патронов), может быть разряжен (с возвратом извлеченных патронов).

**Алгоритм решения.**
В класс `Gun` добавлены методы `reload(int count)` и `unload()`. Метод `reload` вычисляет свободное место в обойме (`fullammo - ammo`). Если запрашиваемое количество меньше или равно свободному месту, оно добавляется, и возвращается 0. Если больше – пистолет заряжается до максимума, а метод возвращает разницу (лишние патроны). Метод `unload` запоминает текущее количество патронов, обнуляет его и возвращает запомненное значение. 

## **№3. Задание 2**

**Неизменяемый список значений.**
Разработать сущность, представляющую собой обертку над массивом целых чисел. Инициализация возможна из массива, перечня чисел (varargs) или другого такого же списка. Реализовать получение, замену значений с проверкой границ, приведение к строке, проверку на пустоту и возврат в виде стандартного массива.

**Алгоритм решения.**
Класс `ImmutableValueList` хранит данные в поле `private final int[] values`. Для предотвращения внешнего изменения массива во всех конструкторах используется `Arrays.copyOf()`, создающий независимую копию данных. Методы `get` и `set` используют вспомогательный метод `checkIndex`, который выбрасывает `IndexOutOfBoundsException` при выходе за границы массива. Метод `toArray()` возвращает `values.clone()`, чтобы внешняя модификация возвращенного массива не влияла на внутренний список.

## **№4. Задание 4**

**Автомат (Наследование).**
Создать сущность Автомат, наследуемую от Пистолета. Автомат имеет скорострельность (неизменяемую), может стрелять очередью и стрелять заданное количество секунд.

**Алгоритм решения.**
Класс `AutomatGun` наследуется от `Gun` (`extends Gun`). Добавлено поле `private final int fireRate`. Конструкторы используют ключевое слово `super()` для корректной инициализации полей родительского класса. Метод `shoot()` переопределен (`@Override`) и содержит цикл, вызывающий `super.shoot()` количество раз, равное скорострельности. Добавлен перегруженный метод `shoot(int seconds)`, который вычисляет общее количество выстрелов (`seconds * fireRate`) и также вызывает метод родителя в цикле.

## **№5. Задание 8**

**Лучший стрелок (Полиморфизм).**
Создать сущность Стрелок, который имеет имя и оружие (абстрактный тип `Weapon`). Стрелок может стрелять.

**Алгоритм решения.**
Класс `Shooter` содержит поле типа `Weapon`. Благодаря механизму полиморфизма (виртуальному вызову методов), при вызове `weapon.shoot()` среда выполнения Java автоматически определяет фактический тип объекта (`Gun` или `AutomatGun`) и вызывает соответствующую переопределенную реализацию метода. Если оружие не выдано (`null`), выводится соответствующее сообщение.

## **№6. Задание 6**

**Сравнение точек.**
Создать сущность Точка с координатами X и Y. Реализовать корректное логическое сравнение двух точек.

**Алгоритм решения.**
Класс `Point` имеет поля `private final int x, y`. Для корректного сравнения объектов по содержимому, а не по ссылке, переопределен метод `equals(Object obj)`. Он проверяет ссылочную идентичность, тип объекта через `getClass()` и равенство координат. Также переопределен метод `hashCode()`, возвращающий `x * 31 + y`, что является обязательным контрактом Java для корректной работы объектов в хеш-коллекциях (`HashSet`, `HashMap`).

## **№7. Задание 7**

**Пакеты и static import.**
Организовать код в пакеты. Реализовать возведение в степень с использованием коротких имен статических методов.

**Алгоритм решения.**
Все классы распределены по логическим пакетам (например, `ru.timofeev.gun`, `ru.timofeev.point`). Точка входа (`main`) вынесена в пакет `ru.timofeev.main`. Для задачи возведения в степень создан класс `Power`, в начале которого использованы директивы `import static java.lang.Integer.parseInt` и `import static java.lang.Math.pow`. Это позволяет вызывать данные статические методы напрямую, без указания имени класса (`Integer.` или `Math.`), что соответствует требованию об использовании коротких имен.
