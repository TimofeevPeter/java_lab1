Создайте	сущность	Время,	которое	будет	описывать	текущее	время	суток	в	24-х	часовом
формате.	 Время	 описывается	 числом	 секунд,	 прошедшим	 с	 начала	 суток.	 Время	 может	 быть

Необходимо	создать	и	вывести	на	экран	текстовую	форму	для	следующих	вариантов	времени:

• 10	секунд

• 10000	секунд

• 100000	секунд

Метод main создаёт три объекта класса Time с заданным количеством секунд (10, 10000, 100000) и выводит результат вызова метода toText() для каждого из них.

Результат форматируется в строку вида “ЧЧ:ММ:СС” с добавлением ведущих нулей при необходимости.

## **№2. Задание 4**

**Сотрудники и отделы.**
Создайте сущность Сотрудник, которая описывается именем (в строковой форме) и отделом, в котором сотрудник работает, причем у каждого отдела есть название и начальник, который также является Сотрудником. Сотрудник может быть приведен к текстовой форме вида: “Имя работает в отделе Название, начальник которого Имя”. В случае если сотрудник является руководителем отдела, то текстовая форма должна быть “Имя начальник отдела Название”.
Необходимо выполнить следующие задачи:
Создать Сотрудников Петрова, Козлова, Сидорова работающих в отделе IT.
Сделать Козлова начальником IT отдела.
Вывести на экран текстовое представление всех трех Сотрудников.

**Алгоритм решения.**
Метод main создаёт объект отдела IT, затем создаёт трёх сотрудников (Петров, Козлов, Сидоров) и назначает им этот отдел через метод setDepartment(). После этого Козлов назначается начальником отдела через метод setBoss().
Класс Employee хранит имя и ссылку на объект Department. Класс Department хранит название и ссылку на сотрудника-начальника. Метод toText() класса Employee проверяет, является ли текущий сотрудник начальником своего отдела (сравнивая ссылки через оператор ==), и формирует соответствующую строку.

## **№5. Задание 1**
**Пистолет стреляет.**
Создайте сущность Пистолет, которая описывается следующим образом:
• Имеет Количество патронов (целое число)
• Может быть создан с указанием начального количества патронов
• Может быть создан без указания начального количества патронов, в этом случае он изначально заряжен пятью патронами.
• Может Стрелять, что приводит к выводу на экран текста “Бах!” в том случае, если количество патронов больше нуля, иначе делает “Клац!”. После каждого выстрела (когда вывелся “Бах!”) количество патронов уменьшается на один.
Создайте пистолет с тремя патронами и выстрелите из него пять раз.

**Алгоритм решения.**
Класс Gun содержит приватное поле ammo для хранения количества патронов. Реализована перегрузка конструкторов: основной конструктор принимает количество патронов, а конструктор без параметров использует цепочку вызовов this(5) для установки значения по умолчанию.
Метод shoot() проверяет условие ammo > 0. Если оно истинно, выводится "Бах!" и значение ammo уменьшается на единицу с помощью оператора декремента (--). Если условие ложно, выводится "Клац!". Метод main создаёт объект Gun с 3 патронами и пять раз вызывает метод shoot().
