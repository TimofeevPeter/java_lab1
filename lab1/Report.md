Пример:
arr1=`[1,2,3]`
arr2=`[7,8,9]`
результат: `[1,2,3,7,8,9]`

**Алгоритм решения**
Метод main считывает две строки чисел, разделённых пробелами. Строки разбиваются методом split, преобразуются в два целочисленных массива и передаются в метод concat.
Метод concat создаёт новый массив, длина которого равна сумме длин исходных массивов. С помощью двух последовательных циклов в новый массив сначала копируются все элементы первого массива, а затем все элементы второго.

## **Задача 5**
 Удалить негатив.
Дана сигнатура метода: public int[] deleteNegative (int[] arr);
Необходимо реализовать метод таким образом, чтобы он возвращал новый
массив, в котором записаны все элементы массива arr кроме отрицательных.
Пример:
arr=`[1,2,-3,4,-2,2,-5]`
результат: `[1,2,4,2]`

**Алгоритм решения**
Метод main считывает строку чисел, преобразует её в массив и передаёт в метод deleteNegative.
Метод deleteNegative реализует двухпроходный алгоритм. В первом цикле он подсчитывает количество неотрицательных элементов. Затем создаётся новый массив точно этого размера. Во втором цикле в новый массив копируются только те элементы исходного массива, которые больше или равны нулю.
