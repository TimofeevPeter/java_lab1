## **№1. Задание 3. Сравнимое**

**Условие:**
Создайте ссылочный тип Сравнимое, гарантирующий наличие по данной ссылке метода со следующими характеристиками:
- Называется "сравнить"
- Принимает объект
- Тип принимаемого объекта может быть изменен без изменения самого Сравнимого
- Возвращает целое число

**Алгоритм решения.**
Создан обобщённый интерфейс `Сравнимое<T>` с методом `int сравнить(T other)`. Типовой параметр `T` позволяет менять тип сравниваемого объекта без изменения интерфейса.
Использованные классы:
- `СравнимоеЧисло` — реализует `Сравнимое<Integer>`. Хранит `private final int value`. Метод `сравнить` возвращает `this.value - other`.
- `СравнимаяСтрока` — реализует `Сравнимое<String>`. Хранит `private final String text`. Метод `сравнить` возвращает `this.text.length() - other.length()`.
- `Main` — создаёт объекты обоих классов и демонстрирует работу метода `сравнить` для разных пар.

## **№4. Задание 3.1. Функция**

**Условие:**
Разработайте такой метод, который будет принимать список значений типа T, и объект имеющий единственный метод apply. Данный метод надо применить к каждому элементу списка, и вернуть новый список значений типа P, при этом типы T и P могут совпадать, а могут не совпадать.
Используйте разработанный метод следующим образом:
1. Передайте в метод список со значениями: "qwerty", "asdfg", "zx", а получите список чисел, где каждое число соответствует длине каждой строки.
2. Передайте в метод список со значениями: 1,-3,7, а получите список в котором все отрицательные числа стали положительными, а положительные остались без изменений.
3. Передайте в метод список состоящий из массивов целых чисел, а получите список в котором будут только максимальные значения каждого из исходных массивов.

**Алгоритм решения.**
Создан обобщённый интерфейс `Transformer<T, P>` с методом `P apply(T value)` и универсальный метод `transform`.
Использованные классы:
- `StringToLength` — реализует `Transformer<String, Integer>`. Возвращает `value.length()`.
- `MakePositive` — реализует `Transformer<Integer, Integer>`. Возвращает `Math.abs(value)`.
- `ArrayMax` — реализует `Transformer<int[], Integer>`. Находит максимум в массиве циклом.
- `ListTransformer` — содержит метод `transform(List<T>, Transformer<T, P>) → List<P>`. Создаёт новый `ArrayList<P>`, в цикле вызывает `transformer.apply(item)` и добавляет результат.
- `Main` — демонстрирует все три примера из условия.

## **№5. Задание 3.2. Фильтр**

**Условие:**
Разработайте такой метод, который будет принимать список значений типа T и объект имеющий единственный метод test (принимает T и возвращает boolean). Верните новый список типа T, из которого удалены все значения не прошедшие проверку условием.
Используйте разработанный метод следующим образом:
1. Передайте в метод список со значениями: "qwerty", "asdfg", "zx", и отфильтруйте все строки имеющие менее трех символов.
2. Передайте в метод список со значениями: 1,-3,7, и отфильтруйте все положительные элементы.
3. Передайте в метод список состоящий из массивов целых чисел, а получите список в котором будут только те массивы, в которых нет ни одного положительного элемента.

**Алгоритм решения.**
Создан интерфейс `Condition<T>` с методом `boolean test(T value)` и универсальный метод `filter`.
Использованные классы:
- `StringLengthAtLeast3` — реализует `Condition<String>`. Возвращает `value.length() >= 3`.
- `IsPositive` — реализует `Condition<Integer>`. Возвращает `value > 0`.
- `HasNoPositive` — реализует `Condition<int[]>`. Проверяет циклом отсутствие элементов `> 0`.
- `ListFilter` — содержит метод `filter(List<T>, Condition<T>) → List<T>`. Создаёт новый список, в цикле вызывает `condition.test(item)` и добавляет элемент только если `true`.
- `Main` — демонстрирует все три примера из условия.

## **№6. Задание 3.3. Сокращение**

**Условие:**
Разработайте такой метод, который будет принимать список значений типа T и способ с помощью которого список значений можно свести к одному значению типа T, которое и возвращается из метода.
Используйте разработанный метод следующим образом:
1. Передайте в метод список со значениями: "qwerty", "asdfg", "zx", и сформируйте одну большую строку, которая состоит из всех строк исходного списка.
2. Передайте в метод список со значениями: 1,-3,7, и верните сумму всех значений исходного списка.
3. Имеется список, состоящий из списков целых чисел, получите общее количество элементов во всех списках. Подсказка: решить задачу можно в одно действие или последовательно использовать методы из 3.3.1 и 3.3.3.
Далее необходимо изменить разработанный метод таким образом, чтобы данный метод гарантированно не возвращал null и не выбрасывал ошибок в том случае, если исходный список пуст.

**Алгоритм решения.**
Создан интерфейс `Combiner<T>` с методом `T combine(T left, T right)` и универсальный метод `reduce` с параметром `identity`.
Использованные классы:
- `StringConcat` — реализует `Combiner<String>`. Возвращает `left + right`.
- `IntegerSum` — реализует `Combiner<Integer>`. Возвращает `left + right`.
- `ListReducer` — содержит метод `reduce(List<T>, T identity, Combiner<T>) → T`. Инициализирует аккумулятор значением `identity`, в цикле обновляет: `result = combiner.combine(result, item)`. Для пустого списка возвращает `identity`.
- `ListSize` — реализует `Transformer<List<Integer>, Integer>`. Возвращает `value.size()`.
- `Main` — демонстрирует все три примера. Третий решается в два этапа: `transform` превращает список списков в список размеров, затем `reduce` складывает размеры. Также показана обработка пустого списка.
